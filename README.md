# foundryvtt-lancer-advanced-automation
Some advanced automation stuff I myself wanted to add to the lancer system for foundryvtt. Currently just a personal beta, use at your own risk. Includes some stuff from non-official sources (e.g. MKII).

## Current Content
> [!IMPORTANT]  
> All content can be disabled/enabled through module settings on a per user basis. Default is fully deactivated module through settings.

- **Compendiums:**
  - Lancer Advanced Automation Items: Includes custom items needed for some automation to work or custom weapon items for non weapon systems to be able to add attack animations for them.
  - Lancer Advanced Automation Macros: Includes macros for manual usage of some systems and functionality and some custom animation macros for selected systems which use special functionality from this module to improve animations.
- **Attacks:**
  - "Improved" custom targeting stuff (e.g. auto untarget and auto remove templates before and/or after attack)
  - Additional data saving to gain increased possibilities for animation macros. (Used in conjunction with [Lancer Weapon FX](https://foundryvtt.com/packages/lancer-weapon-fx))
- **Licenses:**
  - Monarch:
    - Avenger Silo automation + macro for manual usage + custom weapon item.
    - Divine Punishment automation + macro for manual usage.
    - Tlaloc automation + macro for manual deactivation.
    - Pinaka Missile delayed attack automation + MKII swap modular head automation. **(!!! Only with custom item from compendium !!!)**
- **Pilot Talents:**
  - Stormbringer:
    - Normal and MKII support.
    - Seismic Deluge automation. (Only reminds user and posts chat message)
    - Stormbending automation. (Automatic torrent die reduction and reminder + chat message)
    - Torrent Massive Attack automation + macro for manual usage. (Torrent die handling + attack/damage roll support)
    - Torrent MKII automation + macro for manual usage.
- **Core Boni:**
  - Overpower Caliber automation. (Will ask for all weapons, as there is no way to define a weapon which has the core bonus installed yet)

> [!TIP]  
> Custom weapon items for non weapon systems from the compendium can be used to implement attack animations in conjuction with [Lancer Weapon FX](https://foundryvtt.com/packages/lancer-weapon-fx)
